## 영상별 기록

### 1. `sc_city_lead.mp4` — 주간 도심, 앞차
- 원본: https://www.pexels.com/video/4644521/ (2562x1440 30fps, 63초 → 0~45초)
- 장면:
  - 캐나다 도심 4차선
  - 노란 중앙선, 흰 점선
  - 앞에 흰 VW, 오른쪽 차선에 흰 SUV
  - 33~39초: 신호 정지 후 출발
  - 40초 이후: 파란 차가 오른쪽 차선에 있음
- 결과:
  - LDW 약한 경고 2번 (1~3초, 오른쪽 점선 쪽 0.47m)
  - 19.8초 앞차(VW) 선택. 배운 값: 차선 가운데에서 +0.51m, **차 폭 = 차선 폭의 0.73배**. 0.35~0.65 범위를 벗어나서 앞차 값은 쓰지 않음
  - **36.6초 끼어들기 경고 1번 = 오경보**. 정지 신호에서 오른쪽 SUV가 먼저 출발해 멀어지는 장면 (`sheets/sc_city_lead_33-39s.jpg`)
- 차선을 끊었을 때 (`LDW_DROP_AFTER_S=3`):
  - 4.6초 held, 5.6초 virtual
  - **앞차 선택 안 됨**: 광각 카메라라 화면 아래(y=870)에서도 차선 폭이 약 325px. 앞차 조건(그 줄 차선 350px 이상)을 넘는 차가 없음
  - 끼어들기 경고 0 (36.6초 오경보도 안 남)
- 볼 것:
  - 멀어지는 옆 차가 소실점 쪽으로 모이면서 "들어오는" 것처럼 예측되는 경우로 보여. 원인 확인 필요
  - 앞차 조건 350px는 카메라 화각에 따라 달라져야 함 (px 대신 거리나 화면 높이 비율로 정하는 게 맞음)
  - 실제 영상에서 차 폭 ÷ 차선 폭이 0.73 (test3에서는 0.74, 0.55, 0.49). 도심 차선이 좁거나(3.0m) 박스가 넓게 잡히는 것 같아. 범위 0.35~0.65는 다시 볼 필요가 있음

### 2. `sc_tunnel.mp4` — 터널
- 원본: https://www.pexels.com/video/27288183/ (1080p 30fps, 8초)
- 장면: 밝은 터널 조명, 흰 점선·실선, 앞에 빨간 차 → 흰 차들
- 결과: 차선 인식, 경고 없음, 앞차 선택 안 됨 (앞차들이 멀거나 옆 차선)
- 볼 것: 짧아서 반복 재생으로 써야 함

### 3. `sc_night_curve.mp4` — 야간 굽은 길
- 원본: https://www.pexels.com/video/33650283/ (1080p 30fps, 115초 → 0~80초)
- 장면:
  - 미국 시골 2차로, 헤드라이트만
  - 노란 이중 중앙선(왼쪽), 흰 가장자리선(오른쪽)
  - 계속 굽음
  - 1:10쯤 마주 오는 차
- 결과:
  - 차선은 잘 잡힘
  - **왼쪽 강한 경고 13번**: 계속 중앙선 쪽 0.4~0.9m로 계산됨
  - 끼어들기 0
- 볼 것:
  - 실제로는 차선 안을 달리는데 경고가 남
  - 휴대폰이 **운전석(왼쪽)**에 붙어 있으면 카메라가 차 가운데보다 왼쪽이라 이렇게 나와
  - 시골길 차선이 3.5m보다 좁은 것도 영향
  - → 카메라 위치(`cam_offset_m`)·차선 폭 설정이 필요한 사례

### 4. `sc_night_highway(_crop).mp4` — 야간 고속도로
- 원본: https://www.pexels.com/video/15270404/ (1080p 60fps, 26초)
- 장면:
  - 미국 고속도로 5차선, 가로등, 흰 점선
  - 6~8초 오른쪽 차선 흰 차
  - 20초쯤 전광판
- 결과:
  - 원본 구도: **차선 한 번도 인식 안 됨**. 지평선이 화면 아래 70% 높이
  - `_crop` (아래 가운데 1067x600을 확대, 지평선 약 47%): 차선 인식, 경고 0, 오경보 0

### 5. `sc_day_curve_marks(_crop).mp4` — 주간 굽은 고속도로, 노면 표시
- 원본: https://www.pexels.com/video/11367262/ (1080p 60fps, 28초)
- 장면:
  - 튀르키예 2차로 고속도로, 차 거의 없음
  - 0~7초 주황 화살표·횡단선
  - 왼쪽으로 굽음
- 결과:
  - 원본 구도: **차선 인식 안 됨** (지평선 약 68%)
  - `_crop`: 차선 인식, 오른쪽 강한 경고 2번 (14초, 25초, 오른쪽 실선 0.48m)
- 볼 것: 노면 표시로 인한 오경보 없음. 굽은 길에서 오른쪽 실선 쪽으로 붙는 장면에서 경고

### 6. `sc_rain_nolane(_crop).mp4` — 비, 선 없는 길
- 원본: https://www.pexels.com/video/1407842/ (1080p 30fps, 26초)
- 장면: 흑백, 빗방울, 와이퍼가 화면을 가림, 차선 없는 시골길, 앞에 차 1대 (멀리)
- 결과: 원본·`_crop` 모두 차선 인식 안 됨, 경고 없음
- 볼 것: 선이 없는 길에서 아무 경고도 안 나는지 (오경보 확인용)

### 7. `sc_fog.mp4` — 짙은 안개
- 원본: https://www.pexels.com/video/11008653/ (1080p 30fps, 19초)
- 장면: 산길 고속도로, 짙은 안개, 앞에 차 여러 대 (흰 차·빨간 후미등), 노란 가장자리선이 흐리게
- 결과: **차선 한 번도 인식 안 됨** → 도로 모양을 못 배워서 held/lead/virtual도 못 만듦
- 볼 것:
  - "시작부터 차선 없음" 한계의 실제 사례
  - 앞차 기준 차선이 가장 필요한 상황인데, 지금은 차선을 한 번이라도 봐야 쓸 수 있어

| 시작부터 차선이 없으면 아무것도 못 함 | 안개 | 배운 도로 모양을 파일로 저장해 다음 실행에 쓰기 |

## 못 찾은 상황

| 상황 | 이유 |
|---|---|
| **왼쪽에서 끼어드는 차** | Pexels에 차량 앞 카메라로 찍은 끼어들기 영상이 거의 없음 (오른쪽은 `px_5915075`, `test3`) |
| 차선이 보이는 **정체 구간**에서 가까운 앞차 | 찾은 정체 영상은 뒷좌석에서 찍어 계기판이 화면 대부분 (제외) |

→ 직접 찍는 게 가장 좋아:
- 블랙박스 위치(룸미러 뒤, 차 가운데)
- 지평선이 화면 가운데쯤
- 1080p
- 출퇴근 정체 구간과 끼어들기 많은 합류 구간

## 실행

```sh
cd /mnt/user_data/applications
./run_app_wayland_npu.sh misc/image_npu/sc/sc_city_lead.mp4            # 화면으로
./ldw_board_check.sh 45 misc/image_npu/sc/sc_city_lead.mp4             # 결과 파일까지
LDW_DROP_AFTER_S=3 ./ldw_board_check.sh 45 misc/image_npu/sc/sc_city_lead.mp4   # 차선 끊고 앞차 기준 시험
```

PC → 보드 (보드에 없을 때):
```bash
cd ~/apache6-sr-linux_som_micro/applications/misc/image_npu
ssh root@192.168.13.33 mkdir -p /mnt/user_data/applications/misc/image_npu/sc
scp sc/*.mp4 root@192.168.13.33:/mnt/user_data/applications/misc/image_npu/sc/
```

보드 남은 공간: 약 250MB (11/06). 영상을 더 넣을 때는 2.5Mbps로 변환해서 넣기:
```sh
LD_LIBRARY_PATH=$PWD/misc/lib misc/ffmpeg -i in.mp4 -an -vf "scale=1920:1080,fps=15" \
  -c:v mpeg4 -b:v 2500k -maxrate 3000k -bufsize 3000k out.mp4
# 지평선이 너무 아래면 아래쪽을 확대: -vf "crop=1067:600:426:480,scale=1920:1080,fps=15"
```
