# 끼어들기 시험 영상: 위치와 실행 방법

## 1. 영상 위치

| 영상 | PC (VS Code) | 보드 |
|---|---|---|
| `test3_1080p.mkv` | `~/apache6-sr-linux_som_micro/applications/misc/image_npu/test3_1080p.mkv` | `/mnt/user_data/applications/misc/image_npu/test3_1080p.mkv` |
| `px_5915075.mp4` | `~/apache6-sr-linux_som_micro/applications/misc/image_npu/px/px_5915075.mp4` | `/mnt/user_data/applications/misc/image_npu/px/px_5915075.mp4` |

## 2. 영상 내용

| 영상 | 길이 | 장면 | 기대 결과 |
|---|---|---|---|
| `test3_1080p.mkv` | 8.6초 | 국내 블랙박스. **0~1.3초 오른쪽 흰 차가 가까이서 끼어듦**, 5~7초 다시 오른쪽으로 나감 | 약 **1.2초**에 경고 (1초 이상 표시), 나갈 때 경고 없음 |
| `px_5915075.mp4` | 27.5초 | 독일 고속도로 (Pexels). 내 차는 왼쪽 차선. **3~7초 오른쪽 은색 차가 천천히 끼어듦**, 9초쯤 옆 차선 버스 | 약 **3.7초**에 경고 1번, 버스에는 경고 없음 |

- `test3_1080p.mkv`는 아이폰 영상(`test3.mov`)을 보드에서 1920x1080 MPEG-2로 바꾼 파일이야. 원본 `.mov`는 보드가 제 속도로 못 풀어서 쓰지 않아.
- `px_5915075.mp4` 출처: https://www.pexels.com/video/5915075/ (Pexels 무료 라이선스)

## 3. 보드에서 실행

### 접속 (PC 터미널)
```bash
ssh root@192.168.13.33
cd /mnt/user_data/applications
```

### 화면으로 보기
```sh
./run_app_wayland_npu.sh misc/image_npu/test3_1080p.mkv
./run_app_wayland_npu.sh misc/image_npu/px/px_5915075.mp4
```
- 영상은 끝나면 처음부터 반복돼.
- 끝낼 때는 **Ctrl+C** (앱과 영상 공급이 같이 정리됨).
- 경고가 뜨면 화면에 **노란 이중 박스 + `[번호]CUT-IN`**, 아래쪽에 **`CUT-IN WARNING`** 이 나와.

### 로그로 보기
```sh
./run_app_wayland_npu.sh misc/image_npu/test3_1080p.mkv 2>&1 | grep -E "cut-in O|nc_rec_trigger"
```
```
[nc_cutin] ch0 cut-in ON  class:1 id:9 (candidate 136 ms, 3 frames)
[STUB] nc_rec_trigger(1)
[nc_cutin] ch0 cut-in OFF class:1 id:9
```

### 결과 파일까지 남기기
```sh
./ldw_board_check.sh 30 misc/image_npu/test3_1080p.mkv
./ldw_board_check.sh 32 misc/image_npu/px/px_5915075.mp4
```
- 지정한 초만큼 실행 → 종료 → 15초 재실행. 결과는 `ldw_check_<날짜>.txt`.
- **"cut-in"** 항목에서 경고 횟수와 녹화 호출 횟수를 봐. 두 숫자가 같아야 정상이야.
  - test3 30초: `cut-in ON: 3` (반복 3번 × 1번)
  - px_5915075 32초: `cut-in ON: 2   nc_rec_trigger(1) calls: 1` (같은 차가 트럭→승용차로 다시 인식돼 화면 경고는 2번, 녹화는 1번)

### 결과 파일을 PC로 (PC 터미널)
```bash
scp 'root@192.168.13.33:/mnt/user_data/applications/ldw_check_*' ~/apache6-sr-linux_som_micro/board_logs/
```

## 4. 값을 바꿔서 실행 (다시 빌드 필요 없음)

```sh
CUTIN_MIN_LANE_W=150 ./run_app_wayland_npu.sh misc/image_npu/px/px_5915075.mp4
```

| 환경변수 | 기본 | 의미 |
|---|---|---|
| `CUTIN_HORIZON_MS` | 1000 | 예측 시간 (ms) |
| `CUTIN_MARGIN` | 0.10 | 예측 위치가 차선 안쪽으로 들어와야 하는 정도 |
| `CUTIN_MIN_LANE_W` | 200 | 이보다 좁은 차선 폭(먼 차)은 판정 안 함 (px). 120이면 px_5915075 버스에 오경보 |
| `CUTIN_ON_MS` / `CUTIN_OFF_MS` | 100 / 333 | 켜기 / 끄기 |
| `CUTIN_MIN_ON_MS` | 1000 | 경고 최소 표시 시간 |
| `CUTIN_DUP_MS` | 3000 | 같은 차로 보는 시간 (녹화 중복 방지) |

앱이 시작할 때 `[nc_cutin] config: ...` 로그에 적용된 값이 나와.

```bash
scp px/px_5915075.mp4 root@192.168.13.33:/mnt/user_data/applications/misc/image_npu/px/
```
