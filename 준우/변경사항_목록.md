# 준우(A) 변경 위치 목록 — 합치기용 (11/06)

파일 구분과 폴더 안내는 `README.md`. 여기는 **합칠 때 어디를 옮기면 되는지**만 정리했어.
**`wayland_npu_app.c`와 `Makefile`은 여러 사람이 고치는 파일이니까 파일째 덮어쓰지 말고 아래 위치만 옮겨줘.**

## 한눈에 보기

| 파트 | 새파일 (그대로 복사) | 수정파일 (위치만 옮기기) |
|---|---|---|
| 1. 차선이탈경고 + 영상입력 | `ldw/nc_ldw.c`, `ldw/nc_ldw.h`, `misc/run_app_common.sh` | `v4l2/v4l2_interface.c`, `misc/run_v4l2loopback.sh`, `misc/run_app_wayland_npu.sh`, `misc/run_app_wayland_cam.sh` |
| 2. 끼어들기예측 | `cnn/core/nc_traj.c/h` (준이 원본), `cnn/core/nc_cutin.c/h` (준이+준우), `cnn/core/nc_class.c/h` (준우) | `cnn/core/nc_cnn_aiware_runtime.c/h`, yolov8·ufld·pelee·segmentation 후처리 |
| 3. 공통 | `misc/ldw_board_check.sh` (시험도구) | `wayland_npu_app/wayland_npu_app.c`, `wayland_npu_app/Makefile` |

## 1. 차선이탈경고 + 영상입력

### `applications/common/nc_app_modules/v4l2/v4l2_interface.c`
| 위치 | 변경 |
|---|---|
| `nc_v4l2_init_device_and_stream_on()` 바로 위 | `nc_v4l2_wait_loopback_ready()` 추가 (`#ifdef USE_V4L2LOOPBACK`) |
| `nc_v4l2_init_device_and_stream_on()` 맨 앞 | 위 함수 호출: 공급기 첫 프레임까지 최대 10초 대기 |

### 실행 스크립트 (`applications/misc/`)
스크립트는 통째로 내 파일이라 덮어써도 돼. `run_app_common.sh`가 없으면 나머지가 실행 안 돼.

## 2. 끼어들기예측

`diff/수정파일_SDK원본대비.diff`를 SDK에서 `patch -p1`로 적용하거나, 아래 위치를 손으로 옮겨.

| 파일 | 위치 | 변경 |
|---|---|---|
| `cnn/core/nc_cnn_aiware_runtime.h` | `cnn_output_info` 안 `net_id` 다음 | `uint64_t time_stamp_us;` |
| `cnn/core/nc_cnn_aiware_runtime.c` | `run_cnn_program()` `cnn_output.net_id = net_id;` 다음 | `cnn_output.time_stamp_us = time_stamp;` |
| yolov8·ufld·pelee·segmentation 후처리 | `uint64_t time_stamp = 0;` | `= cnn_output->time_stamp_us;` |
| `cnn/networks/yolov8/nc_cnn_yolov8_postprocess.c` | `#include "nc_cnn_tracker.h"` 다음 | `#include "nc_traj.h"` |
| 〃 | `nc_cnn_track(...)` 바로 다음 (`#ifdef USE_BYTETRACK` 안) | `nc_traj_update(cam_ch, net_id, out_cnn_results, cnn_output->time_stamp_us);` |

> 준이 work 저장소에도 같은 내용이 있어 (timestamp 패치). **둘 중 하나만** 남기면 돼.

## 3. 공통

### `applications/wayland_npu_app/wayland_npu_app.c`

| 위치 | 파트 | 변경 |
|---|---|---|
| include 부분 | LDW | `#ifdef USE_LDW` / `#include "nc_ldw.h"` |
| include 부분 | 끼어들기 | `nc_utils.h`, `nc_traj.h`, `nc_cutin.h`, `nc_rec.h`, `#define NC_REC_TYPE_CUTIN (1)` |
| `#define VIS0_MAX_CH` | 영상입력 | `(4)` → `(1)` (1채널 전체 화면) |
| `nc_draw_gl_npu()` 바로 위 | 끼어들기 | `g_disp_frame_ts_us[VIDEO_MAX_CH]`, `PRED_LINE_MIN_PX`, `g_cutin_color` |
| `nc_draw_gl_npu()` DETECTION 분기 | 끼어들기 | 색 배열 만든 뒤 ~ `free(color[i])` 직전: 준이 snippet + 끝에 `nc_rec_trigger(NC_REC_TYPE_CUTIN)` |
| `render()` 프레임 꺼낸 곳 | 끼어들기 | `time_stamp_us = nc_get_mono_us_time();` + `g_disp_frame_ts_us[i] = time_stamp_us;` |
| `render()` 결과 그리기 루프 시작 | 끼어들기 | `nc_traj_predict_frame((int)ch, g_disp_frame_ts_us[ch]);` |
| `render()` LANE_NETWORK 블록 | LDW | `nc_ldw_app_process(ch, lane_buf);` (finish_read 전), `nc_ldw_app_draw(...)` (finish_read 후) |
| `cnn_task()` | 영상입력 | 받은 메시지가 NULL이면 `continue` (종료 시 깨우기용) |
| `npu_init()` ByteTrack 초기화 | 끼어들기 | `#ifdef SHOW_TRI_CHIMERA` → `net_id = NETWORK_TRI_CHIMERA;` |
| `main()` 시작 | LDW | `setvbuf(stdout, NULL, _IOLBF, 0);` |
| `main()` `set_viewport_config();` 다음 | LDW | `nc_ldw_app_init(VIDEO_MAX_CH, ...)` |
| `main()` 끝 (메인 루프 뒤) | 영상입력 | 종료 순서: 화면 정리 먼저 → cnn_task 깨우기 → `pthread_timedjoin_np` 1초 (weston GPU 오류 방지) |

끼어들기 부분 바뀐 줄은 `3_공통/diff/끼어들기_추가부분.diff`.

| 위치 | 파트 | 변경 |
